\section{Functional Scope}

\subsection{Customer Features}

The customer part of the system provides all essential functionalities required to rent vehicles online.

The implemented features include:

\begin{itemize}
    \item \textbf{User registration and authentication}
    \begin{itemize}
        \item creation of a new customer account,
        \item secure login using JWT authentication,
        \item profile management and editing personal information,
        \item account deletion.
    \end{itemize}

    \item \textbf{Vehicle browsing}
    \begin{itemize}
        \item displaying the list of available cars,
        \item viewing vehicle details including model, category, pricing, and rental location.
    \end{itemize}

    \item \textbf{Rental management}
    \begin{itemize}
        \item creating new rental reservations,
        \item selecting pickup and return locations,
        \item specifying rental dates,
        \item automatic calculation of rental costs.
    \end{itemize}

    \item \textbf{Online payment}
    \begin{itemize}
        \item payment for reservations,
        \item support for multiple payment methods,
        \item application of discount coupons during payment,
        \item automatic validation of coupon eligibility.
    \end{itemize}

    \item \textbf{Rental history}
    \begin{itemize}
        \item viewing previous and current rentals,
        \item downloading generated invoices for completed and paid rentals.
    \end{itemize}
\end{itemize}

\subsection{Administrator Features}

The administrative panel provides tools required to manage the rental company's daily operations.

The implemented administrator functionalities include:

\begin{itemize}
    \item \textbf{Fleet management}
    \begin{itemize}
        \item adding new vehicles,
        \item editing vehicle information,
        \item removing vehicles from the fleet,
        \item viewing complete vehicle details.
    \end{itemize}

    \item \textbf{Customer management}
    \begin{itemize}
        \item browsing registered customers,
        \item viewing customer information,
        \item removing customer accounts when necessary.
    \end{itemize}

    \item \textbf{Rental management}
    \begin{itemize}
        \item viewing all rentals within the system,
        \item monitoring reservation status,
        \item accessing invoices associated with rentals.
    \end{itemize}

    \item \textbf{Discount management}
    \begin{itemize}
        \item creating promotional discount codes,
        \item modifying existing discounts,
        \item deleting expired or unused promotions,
        \item viewing available discount campaigns.
    \end{itemize}

    \item \textbf{Lookup data}
    \begin{itemize}
        \item accessing shared lookup data used throughout the administrative interface,
        \item supporting consistent selection of predefined values required by the system.
    \end{itemize}
\end{itemize}

The administrator interface centralizes all operational activities required to maintain the rental service and enables efficient management of business data through a single web application.
